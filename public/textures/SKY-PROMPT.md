# Cosmic panorama

Created with the built-in imagegen tool, as a new raster asset for Orrery.
File: `cosmic-panorama.png`.

## Full generation prompt

Use case: stylized-concept. Asset type: production environment texture for a Three.js browser solar-system viewer. Create a beautiful high-detail 360-degree equirectangular deep-space panorama, 2:1 landscape aspect ratio, ideally 4096 by 2048 pixels. View from inside the galaxy, with an elegant diagonal luminous Milky Way band, intricately layered cosmic dust filaments, delicate translucent nebula clouds in muted violet, dusty rose, and smoky teal, warm ivory galactic light, and large regions of nearly black negative space. Premium astronomical photography blended with cinematic space art, exceptionally fine cloud detail, no blurry oversized stars. A restrained sparse field of tiny pinpoint stars; the app will add sharp foreground stars separately. All detail should be subtle enough behind brightly lit planets. Galaxy structure should extend naturally around the sphere, left and right edges connect seamlessly, top and bottom dark and quiet to avoid pole distortion. Do not depict the galaxy from outside, no spiral galaxy disc, no planets, no Sun, no terrestrial landscape, no horizon, no lens flares, no text, no logo or watermark. Rich and beautiful but predominantly black, never a uniform blue gradient. Save the generated image and report its local file path so it can be integrated into the application.
